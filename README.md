# CS 300 Portfolio Reflection

## What was the problem you were solving in the projects for this course?

The projects focused on creating a program that could help academic advisors organize and look up course information. In Project One, I compared different data structures, and in Project Two I used that planning to build a C++ program that could load, sort, and search course data.

## How did you approach the problem? Why are data structures important to understand?

I compared vectors, hash tables, and binary search trees before choosing a hash table for the final program. This helped me see that data structures are important because they can affect how quickly and efficiently a program can store, search, and organize information.

## How did you overcome any roadblocks you encountered while going through the activities or project?

One challenge was reading the CSV file correctly when courses had different numbers of prerequisites. I also had to work through a few input and file-loading problems, and testing one part of the program at a time made them easier to fix.

## How has your work on this project expanded your approach to designing software and developing programs?

This project made me think more about planning before immediately starting to code. Using pseudocode and comparing data structures first made the final coding portion easier because I already had a better idea of how the program should work.

## How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I have become more aware of separating different tasks into functions and using clear names and comments. I also used input validation and kept the program organized so it would be easier to read, troubleshoot, and change later.
